# Нормоконтроль

Локальный сервис для любого проекта, в том числе кривого: PDF или DWG → отчёт PDF со сносками на нормы. Комплект в `inbox` — пример прогона, не набор марок и помещений, под который пишется проверка.

План работ и правила закрытия этапов: [plan.md](plan.md).

Локальная страница: из корня папки `.venv\Scripts\python.exe scripts\serve.py`, затем в браузере `http://127.0.0.1:8765`. Кабинета и оплаты нет.

Примеры проектов кладите в [inbox](inbox/README.md). Чертежи заказчиков в git не коммитятся.

## Стэк

* Python
* pdfplumber
* ezdwg
* reportlab
* ifcopenshell
